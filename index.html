How PermitIQ Works

End-to-End Intelligence Pipeline

Step 1

Data Collection

Automated Scraping: Our proprietary scraper framework runs daily across 9+ live cities, monitoring government portals (Accela, OpenCounter, Socrata, ArcGIS APIs). Each city's portal structure is mapped and normalized into a unified data model. Rate limiting and error handling ensure 99%+ uptime.

Step 2

Data Processing

Intelligence Layer: Raw permit data is enriched with lead scoring algorithms (project value, permit type, location desirability), deduplication logic removes duplicates, and filtering applies minimum value thresholds ($10K+). Data freshness tracking ensures only recent opportunities are delivered.

Step 3

Territory Matching

Access & Exclusivity Engine: Each opportunity is matched against selected territories (ZIP code + trade type combinations). Subscribers with matching territories receive opportunities (shared access). For territories with active locks, ONLY the lock purchaser receives the opportunity (exclusive access). Territory locks create a competitive moat - once a contractor locks a territory, competitors cannot see opportunities in that territory for the lock period.

Step 4

Delivery & Engagement

Multi-Channel Delivery: Opportunities are delivered via push notifications (mobile), email digests, and in-app feeds. Users can view detailed permit information, property addresses, project values, and contact information (when publicly available). Territory management dashboard shows claim status and competitor activity.
